
# Smart Parking Management System

## Project Description
This project manages parking slots and waiting vehicles using C programming and Data Structures.

## Features
- Park a vehicle
- Exit a vehicle
- Display parking slots
- Display waiting queue
- Search for a vehicle
- Automatically assign a free slot to the next waiting vehicle

## Programming Language
C

## DSA Concepts
- Array
- Circular Queue
- Linear Search

## How to Run

Compile:
gcc main.c -o parking

Run on Windows:
parking.exe

Run on Linux or macOS:
./parking

## Parking Capacity
- 5 parking slots
- 20 waiting vehicles

## Future Enhancements
- Calculate parking fees
- Store entry and exit times
- Save vehicle records in a file
